# Day 23 – Intermediate  
## Build the Pong Game   

## Overview  
On **Day 23** of my **100 Days of Code – The Complete Python Pro Bootcamp**, I built the classic **Pong Game** using **Python Turtle graphics** and **Object Oriented Programming (OOP)**.

Pong is one of the earliest arcade video games where two players control paddles and try to bounce a ball past the opponent’s paddle to score points.

In this project, I implemented paddle controls, ball movement, collision detection, and a scoring system to make the game fully playable.

---

## Project Objectives  
- Create paddles controlled by keyboard inputs  
- Implement ball movement across the screen  
- Detect collisions with paddles and walls  
- Make the ball bounce realistically  
- Add a scoring system for both players  
- Reset the ball after a point is scored
