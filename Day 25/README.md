# Day 25 – Intermediate

## Working with CSV Data and the Pandas Library

## Overview

On **Day 25** of my **100 Days of Code – The Complete Python Pro Bootcamp**, I explored how to work with structured data using **CSV files** and the powerful **Pandas library**.

I started by learning how to read and process CSV data using Python’s built-in tools, then moved on to using **Pandas** for more efficient and flexible data handling. I applied these concepts by analyzing datasets and building a **U.S. States Guessing Game**, where user input is matched with real dataset entries.

This day focused on transforming raw data into meaningful insights and integrating data into interactive applications.

---

## Project Objectives

* Read and process CSV files using Python
* Understand tabular data structures (rows and columns)
* Use the **Pandas library** for data analysis
* Extract, filter, and manipulate dataset values
* Build an interactive guessing game using real data
* Save progress dynamically using file operations

---

## Concepts I Covered

* Reading CSV files (`.read_csv()`)
* DataFrames and Series in Pandas
* Accessing columns and rows
* Filtering data based on conditions
* Converting data to lists
* Iterating through datasets
* Creating new CSV files from processed data
* Using `.to_csv()` for saving results

---

## What I Learned

* How to efficiently handle large datasets using **Pandas**
* The difference between traditional file handling and DataFrame-based operations
* How to filter and query data dynamically
* How to integrate real-world datasets into Python applications
* How to store user progress and generate new data files
* Writing cleaner and more readable data-driven code
