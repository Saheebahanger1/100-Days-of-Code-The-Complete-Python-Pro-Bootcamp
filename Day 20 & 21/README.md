# Day 20 & 21 – Intermediate  
## Build the Snake Game

## Overview
On **Day 20 & 21** of my **100 Days of Code – The Complete Python Pro Bootcamp**, I began building the classic **Snake Game** using **Python Turtle graphics** and **Object Oriented Programming (OOP)**, expanding on the core mechanics.

These days I focused on designing the core mechanics of the game and structuring the project using classes, adding **game features, collision detection, and scoring**, making the game fully playable.

---

## Project Objectives
- Create the snake body using multiple turtle segments
- Implement snake movement logic
- Use OOP to manage game components
- Prepare the foundation for a complete game
- Add food to the Snake Game
- Detect collisions with food, walls, and the snake’s body
- Implement a scoring system
- Handle game-over logic
