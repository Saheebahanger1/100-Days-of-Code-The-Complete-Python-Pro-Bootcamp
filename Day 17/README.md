# Day 17 – Intermediate  
## The Quiz Project & Benefits of OOP

## Overview
On **Day 17** of my **100 Days of Code – The Complete Python Pro Bootcamp**, I built the **Quiz Project** using **Object Oriented Programming (OOP)** principles.  
This day focused on understanding how OOP helps structure programs and manage data more effectively.

---

## Project Objective
- Build an interactive quiz game
- Apply Object Oriented Programming concepts
- Learn how to structure a project using multiple classes
- Improve code readability and scalability

---

## Concepts I Covered
- Classes and objects
- Constructors (`__init__`)
- Attributes and methods
- Managing program state with objects
- Importing classes from multiple files
- Separating logic using OOP design

---

## What I Learned
- How OOP simplifies complex programs
- How objects store data and behavior together
- Why separating responsibilities improves maintainability
- How to build scalable applications using classes
- How to refactor procedural code into OOP-based code

---

## Quiz Project Features
- Question bank loaded from data
- Score tracking system
- User input validation
- Automatic question progression
- Final score display

---

## Files in This Folder
- `main.py` – Main quiz game logic  
- `question_model.py` – Question class  
- `quiz_brain.py` – Quiz logic and state management  
- `data.py` – Question data
