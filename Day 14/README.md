# Day 14 – Beginner
## Higher Lower Game Project

## Overview

On **Day 14** of my **100 Days of Code – The Complete Python Pro Bootcamp**, I built the **Higher Lower Game**, a command-line game where players compare two entities and guess which one has more followers.

This project strengthened my understanding of **functions, loops, conditionals, and data handling** in Python.

---

## Project Objective

* Build an interactive Higher Lower game
* Compare follower counts between two entities
* Track player score across rounds
* End the game when an incorrect guess is made

---

## Concepts Covered

* Functions and return values
* Dictionaries and data structures
* Loops and game flow control
* Conditional logic
* Random data selection
* Game state management

---

## What I Learned

* How to structure a multi-round game
* Managing program state across iterations
* Comparing dictionary values correctly
* Reusing functions for cleaner code
* Improving user experience with clear output

---

## Game Features

* Randomly selected accounts
* Clear comparison output
* Score tracking system
* Game-over logic on wrong guesses
