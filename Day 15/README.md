# Day 15 – Intermediate  
## Local Development Environment Setup & Coffee Machine Project

## Overview
On **Day 15** of my **100 Days of Code – The Complete Python Pro Bootcamp**, I moved into the **Intermediate level** of Python.  
This day focused on setting up a **local development environment** and rebuilding the **Coffee Machine project** to run locally using multiple Python files.

---

##  Project Objectives
- Set up Python locally using a code editor and terminal
- Learn how to run Python scripts outside the browser
- Understand file-based project structure
- Build and run a modular Coffee Machine program

---

##  Concepts I Covered
- Local Python environment setup
- Running Python programs from the terminal
- Python modules and imports
- Project file organization
- Modular programming
- Debugging in a local environment

---

##  Coffee Machine Project Features
- Drink selection menu (espresso, latte, cappuccino)
- Resource management (water, milk, coffee)
- Coin-based payment system
- Transaction validation
- Report generation
- Modular and reusable code structure

---

##  What I Learned
- How to configure and use a local Python environment
- Importance of separating code into multiple files
- How modules improve readability and scalability
- How to debug programs locally
- Transitioning from beginner to intermediate Python development
