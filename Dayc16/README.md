# Day 16 – Intermediate  
## Object Oriented Programming (OOP)

## Overview
On **Day 16** of my **100 Days of Code – The Complete Python Pro Bootcamp**, I learned the fundamentals of **Object Oriented Programming (OOP)** in Python.  
This day marked a major shift from procedural programming to writing **structured, reusable, and scalable code** using classes and objects.

---

## Learning Objectives
- Understand what Object Oriented Programming is
- Learn how to create and use classes and objects
- Work with attributes and methods
- Apply OOP concepts to real-world programs
- Refactor existing projects using OOP principles

---

## Concepts I Covered
- Classes and objects
- Attributes (variables inside classes)
- Methods (functions inside classes)
- Creating multiple objects from a class
- Using constructors (`__init__`)
- Importing and using classes from other files
- Introduction to modular OOP-based projects

---

## What I Learned
- How OOP helps organize complex programs
- Difference between a class and an object
- How attributes store object state
- How methods define object behavior
- Why OOP is useful for large-scale applications
- How to read and understand OOP-based code

---

## Practice Project
- Refactored the **Coffee Machine Project** using OOP
- Used multiple classes to separate responsibilities
- Improved code readability and maintainability
